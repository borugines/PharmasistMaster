白内障・術前術後管理（CME予防）

🏥 疾患
Core 14 / 白内障手術・術後黄斑浮腫予防
初期白内障進行遅延（カリーユニ）。白内障術後3本柱：抗菌点眼（眼内炎予防）＋ステロイド＋NSAIDs点眼（術後黄斑浮腫CME予防）。痛くなくてもNSAIDs継続必須。

点眼手技・点眼日数計算・コンタクト

🏥 疾患
Core 14 / 1滴の科学・点眼順序・防腐剤BAK

カリーユニ点眼用

💊 薬剤
一般名：ピレノキシン
初期老人性白内障進行遅延薬。キノイド物質結合阻止。混濁を透明に戻す薬ではなく進行予防。よく振ってから点眼する懸濁性点眼液。

ブロムフェナク点眼液

💊 薬剤
一般名：ブロムフェナクナトリウム水和物
白内障術後抗炎症点眼薬（NSAIDs点眼）。プロスタグランジン産生を抑制し術後黄斑浮腫（CME）による視力低下を防止。痛みがなくても完遂指導。

オゼックス細粒小児用

テリルジー エリプタ

💊 薬剤
ICS / LABA / LAMA 3剤トリプル合剤 (エリプタ)
喘息・COPD両方に適応を持つ1日1回最強トリプル。複数本の吸入薬を1日1回1吸入に集約。COPDは100エリプタのみ（200は過量査定）。LAMA含有のため閉塞隅角緑内障・前立腺肥大症の排尿障害は禁忌。

ビレーズトリ エアロスフィア

💊 薬剤
ICS / LABA / LAMA 3剤配合共懸濁エアゾール (pMDI)
【COPDのみ適応（喘息適応なし）】共懸濁技術によるpMDI製剤。自力で強く息を吸い込めない重症肺気腫・高齢COPD患者でも霧が気道奥まで届く。1日2回各2吸入。緑内障・前立腺肥大症禁忌。

エブランチルカプセル

💊 薬剤
一般名：ウラピジル（末梢α1遮断＋中枢5-HT1A刺激）
【鑑査の3大急所】
① 適応の二刀流：高血圧症だけでなく「前立腺肥大症に伴う排尿障害」「神経因性膀胱」に適応。降圧と排尿改善を1剤で狙える。
② 起立性低血圧に注意：初回投与時や増量時にめまい・立ちくらみ・ふらつきが出やすいため、就寝前服用や起き上がり時の注意を徹底指導。
③ 粉砕・噛み砕き厳禁：カプセル内は徐放性微粒子。粉砕・すりつぶすと血圧急降下の危険。脱カプセルして顆粒を噛まずに服用は可。

全身性エリテマトーデス（SLE）

🏥 疾患
膠原病・自己免疫疾患 / ループス腎炎・皮膚病変・関節炎
【薬学的管理の急所】
① プラケニル（ヒドロキシクロロキン）：SLEの生命予後を延ばし再燃を防ぐ世界標準薬。「投与前および年1回以上の定期的な眼科精密検査（網膜症モニタリング）」の受診確認が薬剤師の法的責務。
② ループス腎炎の重症化防止：ステロイド（プレドニン）＋免疫抑制薬（セルセプト、ネオーラル）や分子標的薬（ベンリスタ、サフネロー）。尿タンパク・Scr定期追跡。
③ 紫外線対策：光線過敏による疾患再燃を防ぐため、日焼け止め・日傘・長袖着用を徹底指導。

吸入デバイス（DPI / pMDI / SMI）

🌬️ 手技

アグリリンカプセル 0.5mg

エリザス点鼻粉末

💊 薬剤
ドライパウダー点鼻薬 / 1日1回1噴霧
粉末タイプのため液だれや喉への流れ込みが皆無。防腐剤フリー。液状スプレーの刺激や苦味を嫌う患者に最適。強く吸い込まず「軽く自然に吸いながら」噴霧させる。

血管収縮性点鼻薬・薬剤性鼻炎

🚨 濫用警戒
α作動薬 / リバウンド肥厚性鼻炎
即効性はあるが1〜2週間連用でα受容体が脱感作し、薬効消失時に以前より激しく粘膜が腫脹する「点鼻薬中毒（薬剤性鼻炎）」に陥る。市販薬乱用患者は直ちに安全なステロイド点鼻薬へ移行支援する。

💊 薬剤
吸入ステロイド単剤 / 喘息の抗炎症主軸
オルベスコはプロドラッグ設計で声枯れ（嗄声）や口腔カンジダが最少。パルミコート吸入液は自力吸入できない乳幼児喘息発作の救世主。フルタイドは小児・軽症喘息の世界的ゴールドスタンダード。

ホクナリンテープ

💊 薬剤
経皮吸収型β2刺激薬 / 1日1回貼付
結晶レジボアシステムにより24時間安定放出。吸入が難しい小児や認知症高齢者、嚥下困難患者に最適。就寝前貼付で早朝（午前4〜6時）の発作悪化をピンポイント阻止。皮膚刺激防止のため毎日貼る場所を変える。

セレコックス錠

💊 薬剤
選択的COX-2阻害薬 / 1日2回
胃粘膜保護のCOX-1を阻害せず、炎症局所のCOX-2を選択的ブロック。消化性潰瘍リスクが従来のNSAIDsの約半分で変形性関節症・腰痛の長期維持に頻用。スルホンアミド過敏症禁忌、虚血性心疾患リスクに警戒。

カロナール錠 / 細粒 / 坐薬

💊 薬剤
中枢性解熱鎮痛薬 / 圧倒的安全性
末梢COX阻害が極めて弱く、胃潰瘍・腎血流低下・血小板阻害がゼロ。小児、妊婦、授乳婦、CKD高齢者に第一選択。成人の鎮痛では1回500〜1000mgへの適切な用量増量が必要（少量だと無効）。肝機能障害・過量投与に注意。

アンチ・ドーピング（うっかりドーピング防止）

🏃‍♂️ スポーツ薬学
WADA / JADA 禁止物質基準 ＆ 安全OTC
「知らなかった」は通用せず一発失格。総合風邪薬・鼻炎薬のエフェドリン類、葛根湯などの麻黄（マオウ）、南天のど飴のヒゲナミン（β2作動薬）が3大地雷。ステロイド点鼻や吸入は使用可能。必要時はTUE（治療使用特例）申請。

家族性地中海熱（FMF）

🏥 疾患
自己炎症性疾患 / 周期性発熱・漿膜炎・AAアミロイドーシス
【処方鑑査のウラ読み勘所】
① コルヒチンは「毎日漫然と飲むのが正解」！：痛風発作時の「予兆期頓用」と異なり、FMFでは「発作の抑制および致死的なAAアミロイドーシス（腎死）防止のため毎日生涯内服する維持療法薬」！漫然投与と誤解して疑義照会・中止しないこと。
② 自己炎症性 vs 自己免疫性の違い：自己抗体（抗核抗体など）は陰性。インフラマソームの暴走によるIL-1β過剰産生が病態。
③ コルヒチン不応例：抗IL-1β抗体製剤（カナキヌマブ［イラリス］皮下注）の適応あり。

パーキンソン病（PD）

🏥 疾患
神経変性疾患 / 中脳黒質ドパミン神経脱落・4大運動症状 ＆ 運動合併症
【処方鑑査・服薬指導の要点】
① 初期選択の年齢基準：70〜75歳未満はドパミンアゴニスト（DA）先行で将来のジスキネジア発現を遅延。70〜75歳以上や認知症合併例は効果が確実なL-ドパ/DCI配合錠を第一選択。
② 運動合併症の処方設計：ウェアリング・オフ（OFF期）にはL-ドパ分服回数増、COMT阻害薬（オンジェンティス）、MAO-B阻害薬（エクフィナ/アジレクト）、A2A拮抗薬（ノウリアスト）を追加。ピーク時ジスキネジアにはL-ドパ減量＋アマンタジン。
③ 現場の3大警戒：胃腸薬（プリンペラン・ナウゼリン・ドグマチール）のD2遮断による悪化厳禁、MAO-B阻害薬のセロトニン症候群併用禁忌、急激な中断による悪性症候群（NMS）。

オンジェンティス錠 25mg

💊 薬剤
一般名：オピカポン（1日1回就寝前 / 新世代末梢持続型COMT阻害薬）
【服薬指導 ＆ 鑑査急所】
① 1日1回就寝前の新世代COMT阻害薬：従来のエンタカポン（コムタン：L-ドパ服用ごとに毎回内服、最大8回/日）と異なり、1日1回就寝前のみの内服で24時間安定してL-ドパ血中濃度を底上げしOFF時間を大幅短縮。
② 【服薬指導必須】食前・食後1時間あける：食事（特に高脂肪・高蛋白食）でバイオアベイラビリティが激減するため、「就寝前、かつ夕食後から1時間以上経過後」の服用を徹底指導。
③ 尿の赤褐色着色 ＆ ジスキネジア：代謝物により尿が赤褐色やオレンジ色に着色（無害である旨を事前説明）。L-ドパ作用増強によるジスキネジア発現時はL-ドパ減量を考慮。

エクフィナ錠 50mg

💊 薬剤
一般名：サフィナミドメシル酸塩（MAO-B選択的阻害 ＋ グルタミン酸放出抑制）
【服薬指導 ＆ 鑑査急所】
① デュアルアクションでOFF期短縮：高選択的・可逆的MAO-B阻害によるドパミン分解抑制に加え、電位依存性Naチャネル阻害により過剰なグルタミン酸放出を抑制するハイブリッド薬。
② 【併用禁忌リスト：セロトニン症候群】に厳重警戒：抗うつ薬（SSRI/SNRI/三環系）、オピオイド鎮痛薬（トラマドール等）、市販薬にも含まれる鎮咳薬メジコン（デキストロメトルファン）との併用は致死的セロトニン症候群のリスクのため絶対禁忌！
③ 用量調整：通常1日1回50mgから開始、効果不十分時に100mgへ増量。

アジレクト錠 0.5mg / 1mg

💊 薬剤
一般名：ラサギリンメシル酸塩（第2世代非可逆的MAO-B阻害薬 / 単剤・併用両用）
【服薬指導 ＆ 鑑査急所】
① 初期単独から進行期までカバー：L-ドパ併用では1mg 1日1回、単独療法では0.5mg〜1mg 1日1回。脳内ドパミン分解を持続的にブロック。
② アンフェタミン代謝物なし：エフピー（セレギリン）と異なりアンフェタミン骨格を生じないため、動悸、精神興奮、不眠が少ない。
③ 【併用禁忌】：抗うつ薬（SSRI/SNRI/三環系）、トラマドール、デキストロメトルファン（メジコン）との併用は重篤なセロトニン症候群を引き起こすため禁忌。他剤切り替え時の休薬期間にも配慮。

ノウリアスト錠 20mg

💊 薬剤
一般名：イストラデフィリン（世界初アデノシンA2A受容体拮抗薬 / 非ドパミン系新機序）
【服薬指導 ＆ 鑑査急所】
① 運動抑制ブレーキを解除する新機序：線条体間接路のアデノシンA2A受容体を遮断し、過剰な運動抑制ブレーキを解除。ドパミン受容体を直接刺激しないため、ジスキネジアを誘発・増悪させにくい。
② ウェアリング・オフの改善：L-ドパ含有製剤と併用してOFF時間を短縮。通常1日1回20mg、最大40mg。
③ 【最重要鑑査：喫煙で血中濃度半減】：タバコ煙中の多環芳香族炭化水素が肝CYP1A2を強力誘導するため、喫煙者では本剤の血中濃度が約50%に半減する。喫煙患者では初回から40mg投与を検討（問診での喫煙歴確認が不可欠）。

🏥 疾患

① 致死率10〜20%の最緊急病態：抗精神病薬の急な開始・増量、または抗パーキンソン病薬の急激な中断・自己減量・脱水により数日〜数週かけて進行。
② 4大徴候（Levenson基準）：①38〜40℃超の急激な超高熱 ②鉛管様筋固縮（手足がガチガチ、腱反射は正常〜低下） ③自律神経症状（大量発汗・頻脈・血圧急変） ④意識障害（昏迷・混濁）。

④ 特効薬：直ちに原因薬中止（PD薬中断時は即再開）＋筋弛緩薬ダントロレン（ダントリウム）静注＋ブロモクリプチン。

外用ステロイド 5段階強さランク（日本皮膚科学会基準）

ステロイド外用薬は血管収縮試験等の力価に基づき5段階に厳密に分類される：
① Ⅰ群（Strongest：最強）：デルモベート、ダイアコート（手掌・足底の重症角化性病変限定。顔面・陰部・小児は原則禁忌）
② Ⅱ群（Very Strong：非常に強力）：アンテベート、フルメタ、マイザー、トプシム（成人の体幹・四肢の急性増悪の主力）
③ Ⅲ群（Strong：強力）：リンデロン-V/VG、ボアラ、ベトネベート（成人軽〜中等症、小児中等〜重症。処方頻度No.1）
④ Ⅳ群（Medium：中程度）：ロコイド、キンダベート、アルメタ、リドメックス（顔面・首・陰部・乳幼児の安全な第一選択）
⑤ Ⅴ群（Weak：弱い）：プレドニゾロン、オイラックスH（乳幼児の顔面・陰部・眼瞼周囲の軽微な皮膚炎）

関連疾患：アトピー性皮膚炎 / 接触皮膚炎 / 湿疹
皮膚科・薬物動態 鑑査急所

外用薬の経皮吸収率マップ（前腕屈側＝1.0基準の倍率比）

皮膚の角層の厚さと毛包密度による吸収率倍率（Feldman & Maibachデータ）：
・陰部（陰嚢）：42倍（身体中突出して最薄角質。超ハイリスク ➔ Ⅳ群以下限定）
・頬（顔面）：13倍（角層薄く毛細血管豊富。酒さ様皮膚炎リスク ➔ Ⅳ群以下限定）
・額・首：6.0倍（薄く皮膚萎縮を起こしやすいデリケート部位）
・頭皮：3.5倍（毛包開口部多く浸透大 ➔ ローション/フォーム剤選択）
・背中・体幹：1.7倍（標準的な体幹 ➔ Ⅱ〜Ⅲ群）
・前腕屈側（基準）：1.0倍（四肢 ➔ Ⅱ〜Ⅲ群）
・手掌（手のひら）：0.83倍（角質厚い ➔ Ⅰ〜Ⅱ群）
・足底（足の裏）：0.14倍（前腕の約1/7しか浸透しない極厚角質 ➔ Ⅰ群必須）

原則：高吸収部位（顔・陰部）にはMedium以下、難浸透部位（手足）にはStrongest
