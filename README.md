# 💊 臨床薬学マスターポータル (Clinical Pharmacy Master Portal)
> **150疾患・鑑別・同効薬比較・指導 統合実務OS / PWA対応**

薬剤師・薬学生・医療従事者のための、処方監査・病態鑑別・服薬指導支援ポータルです。  
スマートフォン・タブレット・PCの全デバイスに対応し、オフラインでも動作するPWA（Progressive Web App）仕様です。

---

## 🌟 主な機能
1. **🧩 対話型・病態特定プログラム（Prescription Profiling Wizard）**
   - 処方箋の1剤を入力すると、鑑別の決め手となる「併用薬・用量」および「🗣️ 患者への自覚症状問診」を動的提示。
   - ベイズ推論により、確率の高い疾患・詳細病態（サブタイプ・ステージ）を特定。
2. **🩺 全46疾患 症状確認（病態由来）＆ 薬剤モニタリング総合マスター**
   - 病態由来の自覚症状と、薬剤別の有効性・初期副作用モニタリングを対比。
3. **🏆 処方箋受付頻出疾患ランキング TOP150**
4. **📚 全150疾患 臨床インデックス事典**
5. **🧪 臨床検査値 ＆ ⚡ 腎機能・減量シミュレーター**
6. **📖 29大疾患 Core ガイドライン ＆ 処方ウラ読み**
7. **🕵️‍♂️ 処方鑑別プロファイリング ＆ カメレオン薬剤マトリクス**
8. **⚔️ 同効薬ガチンコ比較（使い分け・PK/PD）**

## 📱 スマートフォンでの使い方（ホーム画面に追加）
本アプリは **PWA（Progressive Web App）** に対応しています。
スマートフォンのホーム画面に追加することで、ネイティブアプリのように全画面・オフラインで利用できます。

### 🍎 iPhone (Safari)
1. Safari で公開URLを開く
2. 画面下の **共有ボタン**（四角から矢印が出ているアイコン）をタップ
3. メニューから **「ホーム画面に追加」** を選択

### 🤖 Android (Chrome)
1. Chrome で公開URLを開く
2. 画面右上の **メニューボタン**（縦の3点リーダー）をタップ
3. **「アプリをインストール」** または **「ホーム画面に追加」** を選択
